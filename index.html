About

I'm a Brazilian electrical engineering student, now in Toulouse following the Energy track of the 3EA department at INP-ENSEEIHT, as part of a double degree with the Federal University of Santa Catarina (UFSC).

Before engineering I trained as a systems development technician, so code is a natural tool for me. At UFSC's LABSPOT lab I worked on distribution networks with distributed generation, simulating them in OpenDSS and forecasting their load with machine learning. I've also built embedded measurement tools, such as a real-time current harmonics analyzer.

What I enjoy most is research and development: taking a complex physical problem, understanding it, and turning that understanding into a model, a tool or a prototype that works. That's the kind of work I'm looking for, across a broad range of topics in electrical engineering and energy.

Brazilian and Italian citizen: no visa needed to work in the EU.

Projects

Load forecasting in active distribution networks

2025 – 2026

A full machine learning pipeline for forecasting load in low-voltage networks with distributed generation, based on PMU data: time-series analysis, feature engineering, training, validation and critical evaluation of the models. Research at LABSPOT, UFSC; a paper is in preparation.

Tools: Python, Pandas, Scikit-learn, Matplotlib

sds-run: automated network simulations

2025

A Python command-line tool that automates quasi-static time-series (QSTS) power-flow simulations in OpenDSS on SMART-DS feeders, producing data for networks with distributed solar and batteries.

Tools: Python, OpenDSS, SMART-DS

Source code on GitHub

Real-time current THD analyzer

2026

An embedded analyzer on an ESP32-C3 (RISC-V) with an ACS712 current sensor. It computes True RMS, DC level and current THD on the board, with an FFT written from scratch in C and a FreeRTOS task architecture.

Tools: C, ESP-IDF, FreeRTOS, FFT

Source code on GitHub

PET Greenhouse monitoring

2024 – 2025

An environmental monitoring system on a microcontroller, with Bluetooth communication and a real-time dashboard.

Tools: C++, Bluetooth, Python, Streamlit
